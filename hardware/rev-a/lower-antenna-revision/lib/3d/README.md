# Local 3D models

Sensirion_SCD4x.step is the official [Sensirion model](https://sensirion.com/media/documents/260AFF2D/616531AE/Sensirion_CO2_Sensors_SCD4x_STEP_file.step). Its board model offset is +0.829 mm in Z to align its contact plane with the PCB surface.

SW_SPDT_CK_JS102011SAQN.step is a simplified envelope generated by the accompanying Python source using the [C&K JS drawing](https://www.ckswitches.com/media/1422/js.pdf). Cosmetic details and lead bends are simplified; use the manufacturer drawing for release checks.

Optional components retain their DNP flags. Enable “Show DNP footprints” in KiCad’s 3D viewer to see the optional SCD41 and e-paper parts.
